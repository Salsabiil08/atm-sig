# 10 — Glosarium

| Istilah | Arti |
|---|---|
| GM | General Manager, memimpin departemen |
| SM | Senior Manager, memimpin unit (SM Accounting, SM Reporting) |
| Manager | Memimpin satu section |
| Staff/PIC | Person in Charge, pemegang task |
| Spectator | Role default, hanya baca |
| Section | Subunit di bawah unit (7 section) |
| Evidence | Bukti penyelesaian task (file atau link) |
| Support | Bantuan yang dibutuhkan PIC dari pihak lain |
| Checkpoint | Titik 50%, 80%, 90% waktu berjalan |
| Waktu berjalan (%) | (sekarang − mulai) / (tenggat − mulai) × 100 |
| Lewat | Penanda task yang melewati tenggat |
| CR | Change Request, usulan perubahan scope |
| ADR | Architecture Decision Record |
| Kanban | Papan task dengan kolom per status (CR-0001) |
| Timeline | Tampilan bar mulai–tenggat per task dan beban kerja per orang (CR-0001) |
